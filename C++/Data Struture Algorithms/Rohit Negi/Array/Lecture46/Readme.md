### Pointer RelationShip with array :- 
So pointer store's the address of the different types of variables like int, char, float, etc So array bhi ek tarah ka data type bhi hota hai, so pointer iska bhi address store kar sakta hai. 

Storing the element of the array:-
int arr[5] = {11,2,44,55,66};
int *ptr = &arr[0]; 
- arr[0] kis type ka hai? int type ka then pointer bhi int type ka hoga.
- if we got the address of the first element of the array then we can find out the address of the all element, as if the data is of int type then the difference id of 4 bytes b/w the element. And we also know that ki ram is byte addressable which means ki every byte ko address milega. 
- we have also learnt that ki arr hota hai wo bhi first element ke address ko he store karwata hai. 
  - arr -> store the address of the oth index.
  - arr +1 -> address of the 1st index
  - arr +2 -> address of the 2nd index.

  How this value are generated by the CPU? 
  ith index = Base Adress + i*dataTypeSize
  ex 2nd = 500 + 2*4 = 508

Code Implementation :- 
```cpp
#include <iostream>
using namespace std;

int main()
{
    int arr[5] = {1, 2, 3, 4, 5};

    // Print the address of first element or oth index
    cout << arr << endl; // 1st method
    cout << arr + 0 << endl;  // 2nd method
    cout<<&arr[0]<<endl; //3rd method

    int *ptr = arr;
    cout<<ptr<<endl; // 4th method

    // Print the address of 2nd element or 1st index
    cout<<arr+1<<endl;
    cout<<&arr[1]<<endl;

  
    // Print the value of 0th index 
    cout<<arr[0]<<endl;
    cout <<*arr << endl;
    cout<<*(arr + 0)<< endl;
    cout<<*ptr<<endl; 


    // Printing the all address of the array
    for(int i=0;i<5;i++)
    cout<<arr+i<<endl;

    // Saare value ko print kara do
    for(int i=0;i<5;i++)
    cout<<*(arr+i)<<endl;
    
}
```

2. Range Operations :- 
So isme out of bound bhi ja sakte hai means ki array ke bahar ke element bhi access kar sakte hai lakin aisa karna nahi chahiye. 
:- *(ptr+1) : ptr ke current position mai +1  -> 508 +1 *4 = 512
:- *(ptr-2) : ptr ke current position se 2 kadam pichhe -> 508 - 2 *4 = 500


### Can we do the arithmatic operation on the array ?
So ham aisa nahi kar sakte like arr-- and arr++ as ki pointers variable hamesha constant address ki store karta hai jisko ham kabhi bhi change nahi kar sakte. Means ki arr ke ander koi value aa gaya toh hamesha wahi value rahega, ham iske ander baar baar address change nahi kar sakte ji ek baar aa gaya hai wahi rahega.  Lakin ham pointer variable ke sath arithmatic operation karwa sakte hai. 

Reason :- 
- like hamne ek intger banaya, int num=5;
So symbol table of the this variable having the different attribut name : num, address :200 etc jo bhi chiz ham symbol table mai store kar diye usko ham change nahi kar sakte. Change nahi kar sakte because, kyuki agar ham change karne lage toh, like thik hai ham apni address ko change kar dete hai apne according then aisa possibility aa sakti hai ki do value ko ek he address assign ho gaye ho aur data loss ke bhi possibility bad jaaye. So Memory allocation ka kaam CPU khud karta hai. So isiliye rule bana diya faya ki agae symbol table mai ek baar value chali gai, toh constant he rahengi. 

Note :- So ham referenceVariable(*ptr) mai stored value ko change kar sakte hai but wo jaha stored hai us value ko change nahi kar sakte.
